## Discussion

The spatial and Fourier implementations produced equivalent outputs for every tested filter.
MAE values are around `1e-14` to `5e-13`, and MSE values are around `1e-27` to `4e-25`. These
are floating-point residuals, not visible image differences.

The small nonzero values come from floating-point arithmetic, FFT roundoff, and the inverse FFT
returning tiny imaginary components that are discarded after measurement. The largest kernels
show larger absolute residuals because each output value combines more floating-point operations.

Padding and boundary handling are the main correctness risks. The validation path forces zero
boundary conditions in both implementations. The Fourier path pads enough to compute linear
convolution over the cropped region and aligns the kernel center before the FFT. If either step
is removed, the output may be shifted or polluted by circular wraparound.

For small kernels, spatial filtering is often preferable because direct convolution has low
overhead and OpenCV's implementation is optimized. Fourier-domain filtering requires FFT and
inverse FFT setup costs, but it becomes attractive for large kernels or repeated filtering where
frequency-domain multiplication can be cheaper than large spatial convolution.
